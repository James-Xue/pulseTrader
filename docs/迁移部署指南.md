# pulseTrader + XAU v10 / LLM 迁移部署指南

本文用于把当前机器上的 **Qt 模拟盘 + v10 策略 + SQLite 队列 + LLM overlay** 迁移到另一台 Windows 电脑。

> 交易边界：这是 **paper / 模拟盘** 部署。不要配置真实下单密钥，不要让新机器直接连接真实账户。
>
> 本文中的盘符和目录都是示例；新机器请按实际路径替换。代码和策略的路径以**环境变量 / `xau_config.json`** 为准，不要散落修改 Python 文件里的默认值。

---

## 1. 迁移总览

当前运行链路：

```text
Gate TradFi 公共行情
        │
        ├── gold_snapshot.py / xau_store_data.py
        │       ├── latest_snapshot.json
        │       └── xauusd_cfd_1m.db（研究数据仓库）
        │
        ├── xau_model_fast.py（v10 每秒 runner）
        │       ├── xau_model.py（信号模型）
        │       ├── xau_llm_overlay.py（LLM 顾问否决层）
        │       ├── xau_signal_queue.py（SQLite 队列生产者）
        │       └── xau_manage.py（持仓管理）
        │
        └── xau_signal_queue.py --loop（单一路由消费者）
                │
                └── external_signal.json
                        │
                        ▼
                Qt pulsetrader_ui（模拟撮合、账户、订单历史）
                        │
                        └── external_ack.json → 队列状态 → v10
```

运行进程应当只有：

1. `pulsetrader_ui.exe`：Qt 模拟盘，负责登录、行情引擎、模拟撮合、历史记录。
2. `xau_signal_queue.py --loop`：队列消费者，必须单实例。
3. `xau_model_fast.py --loop ... --strategy-id v10 --signal-queue`：v10 策略 runner。
4. 可选：`xau_store_data.py --loop`：历史 1m K 线采集器。
5. 可选：Claude Code 的 `/loop 5m /xau-llm-overlay`：只写顾问 JSON，不下单。

判断原则：

- **需要作为历史依据的**：保留 `sim_orders.db`、整理后的每日复盘、关键版本报告、最终研究结论；放到 `xau_data`，不要放代码仓库。

- **代码仓库只保留可复现的源码、策略文件、配置样例和文档**；不要用 git 存 443MB 的版本报告或几千个快照。

## 3. 新机器环境准备

### 3.1 推荐版本

| 组件 | 当前机器 | 新机器建议 |
|---|---|---|
| Windows | Windows 10/11 64-bit | Windows 10/11 64-bit |
| Visual Studio | VS 2022 | VS 2022，安装“使用 C++ 的桌面开发” |
| CMake | 3.25+ | 3.25+ |
| Qt | 6.5.3 MSVC2019 64-bit | 同版本最稳；至少 Qt 6.5 |
| vcpkg | 已安装 | 设置 `VCPKG_ROOT` |
| Python | 3.8.0 | 3.8+；建议 3.10/3.11，先跑 `check_env.py` |
| Git | 已安装 | 最新版 |

Qt 需要包含 **Widgets** 和 **Sql** 模块。Qt Sql 还需要 SQLite 驱动插件 `qsqlite.dll`，否则历史交易对话框会打不开或数据库连接失败。

### 3.2 安装 vcpkg 依赖

如果新机器没有 vcpkg：

```powershell
git clone https://github.com/microsoft/vcpkg.git C:\vcpkg
C:\vcpkg\bootstrap-vcpkg.bat
[Environment]::SetEnvironmentVariable("VCPKG_ROOT", "C:\vcpkg", "User")
```

重新打开终端，让 `VCPKG_ROOT` 生效。

### 3.3 目录建议

```text
D:\quant\
  pulseTrader\                 # git 仓库（Qt 源码）
  quantification_platform\
    ce\                        # 策略代码、配置、strategy 文档
    xau_data\                  # 运行数据、历史、研究报告（不进 git）
      sim\                     # Qt 模拟账户/订单/外部信号/队列
  XAUUSD_Data\                 # 1m K 线数据仓库（可选）
```

Qt 的构建目录放在 `pulseTrader\build`。Qt 默认数据目录是：

```text
pulseTrader\build\apps\pulsetrader_ui\Debug\data
```

本方案通过 `PULSETRADER_SIM_DATA_DIR` 把 Qt 的模拟账户/订单/外部信号统一指向：

```text
quantification_platform\xau_data\sim
```

`gate-sim` 启动脚本会把 `xau_config.json` 里的 `sim_data_dir` 注入 Qt 子进程；否则 Qt 会回落到 `Debug\data`。

## 4. 迁移步骤

### 4.1 复制 Qt 源码

```powershell
cd D:\quant
git clone https://github.com/James-Xue/pulseTrader.git pulseTrader
cd pulseTrader
git checkout <你在旧机提交的分支>
```

如果旧机还有未提交改动，先在旧机完成提交/推送，再在新机拉取。不要用 `build/`、`build_test/`、`vcpkg_installed/` 作为源码迁移。

### 4.2 复制策略运行目录

把旧机 `quantification_platform\ce` 复制到新机，例如：

```powershell
robocopy "\\OLD-PC\share\quantification_platform\ce" "D:\quant\quantification_platform\ce" /E ^
  /XD __pycache__ exec_signals auto_manage reviews reports ^
  /XF *.lock *.pyc *.log .llm_overlay_tmp_*.json latest_snapshot.json live_snapshot.json
```

至少要保证第 2.2 节的“最小运行文件”全部存在。

### 4.3 配置路径

把示例配置复制成实际配置：

```powershell
Copy-Item D:\quant\pulseTrader\docs\xau_config.example.json `
          D:\quant\quantification_platform\ce\xau_config.json
```

编辑 `xau_config.json` 的五个路径：

```json
{
  "work_dir": "D:/quant/quantification_platform/ce",
  "data_dir": "D:/quant/quantification_platform/xau_data",
  "sim_data_dir": "D:/quant/quantification_platform/xau_data/sim",
  "sim_app_dir": "D:/quant/pulseTrader/build/apps/pulsetrader_ui",
  "sim_exe": "D:/quant/pulseTrader/build/apps/pulsetrader_ui/Debug/pulsetrader_ui.exe",
  "analysis_cadence": "1m_all"
}
```

Windows 路径建议在 JSON 中使用正斜杠 `/`，避免转义问题。

也可以在启动脚本中设置环境变量，环境变量优先级最高：

```powershell
$env:XAU_WORK_DIR = "D:\quant\quantification_platform\ce"
$env:XAU_DATA_DIR = "D:\quant\quantification_platform\xau_data"
$env:PULSETRADER_SIM_DATA_DIR = "D:\quant\quantification_platform\xau_data\sim"
$env:PULSETRADER_APP_DIR = "D:\quant\pulseTrader\build\apps\pulsetrader_ui"
$env:PULSETRADER_EXE = "D:\quant\pulseTrader\build\apps\pulsetrader_ui\Debug\pulsetrader_ui.exe"
```

**一致性要求：** Qt、`xau_signal_queue.py`、`xau_model_fast.py`、`xau_manage.py` 必须看到同一个 `sim_data_dir`；所有读取/写入快照、审计、manager 报告的 Python 进程必须看到同一个 `data_dir`。否则会出现“队列 accepted，但 Qt 看不到持仓/信号”或“v10 读取旧快照”的分裂状态。

### 4.4 配置 Gate 凭据

在 Qt 的工作目录创建 `.env`：

```powershell
Copy-Item D:\quant\pulseTrader\.env.example `
          D:\quant\pulseTrader\build\apps\pulsetrader_ui\.env
notepad D:\quant\pulseTrader\build\apps\pulsetrader_ui\.env
```

填入 Gate **模拟/测试** API key：

```dotenv
GATE_MAINNET_API_KEY=REPLACE_WITH_PAPER_API_KEY
GATE_MAINNET_API_SECRET=REPLACE_WITH_PAPER_API_SECRET
```

说明：

- 当前 C++ 也接受 legacy 名称 `GATE_API_KEY` / `GATE_API_SECRET`。
- `.env` 不得提交 git、不得发到聊天/文档、不得打包进压缩包。
- 新机器第一次登录时也可以手工输入，勾选“记住”让程序写 `.env`。

### 4.5 构建 Qt（只构建 Debug，不构建测试）

先关闭旧机器/新机器上正在运行的 `pulsetrader_ui.exe`。如果 exe 被占用，构建会失败。

```powershell
cd D:\quant\pulseTrader
$env:VCPKG_ROOT = "C:\vcpkg"

cmake -B build -S . `
  -DCMAKE_BUILD_TYPE=Debug `
  -DCMAKE_TOOLCHAIN_FILE="$env:VCPKG_ROOT\scripts\buildsystems\vcpkg.cmake" `
  -DQt6_DIR="C:\Qt\6.5.3\msvc2019_64\lib\cmake\Qt6" `
  -DPULSE_BUILD_TESTS=OFF `
  -DPULSE_BUILD_UI=ON

cmake --build build --config Debug --target pulsetrader_ui -j 8
```

说明：

- 本项目使用 C++20、CMake 3.25+、vcpkg 和 Qt 6。
- 按当前项目习惯，只构建 Debug 主程序，不构建/运行单元测试。
- 如果 Qt 安装在别处，改 `-DQt6_DIR=...` 或设置 `CMAKE_PREFIX_PATH`。
- 如果构建时报 `pulsetrader_ui.exe` 被占用：关闭 Qt，必要时把旧 exe 改名成 `.old_<时间>`，再重试。
- 如果运行时提示缺少 Qt DLL，使用：

```powershell
& "C:\Qt\6.5.3\msvc2019_64\bin\windeployqt.exe" `
  --debug "D:\quant\pulseTrader\build\apps\pulsetrader_ui\Debug\pulsetrader_ui.exe"
```

并确认 `sqldrivers\qsqlite.dll` 被部署。

### 4.6 准备 Python

v10 运行链路只使用 Python 标准库；`ce` 不需要执行 `pip install -r requirements.txt`。

```powershell
cd D:\quant\quantification_platform\ce
python --version
python check_env.py
```

`check_env.py` 会检查：

- `xau_config.json` / `work_dir`
- `data_dir`
- 策略文件
- Qt 数据目录
- Qt exe
- Gate API 是否可访问

### 4.7 数据仓库（可选）

如果只是跑 v10 模拟盘，可以先不迁移历史 K 线库；`gold_snapshot.py` 会实时从 Gate 拉行情。

如果要保留研究数据：

```powershell
# 先停止旧机/新机的 collector，避免复制到写入中的数据库
robocopy "\\OLD-PC\share\XAUUSD_Data" "D:\quant\XAUUSD_Data" /E ^
  /XF *.lock *.log
```

Gate TradFi 的 kline 接口只提供最近约 500 根，没有时间范围参数；完整历史必须从旧数据库 seed，或者从现在开始持续采集。

首次建立数据仓库：

```powershell
cd D:\quant\quantification_platform\ce
python xau_store_data.py `
  --store-dir D:\quant\XAUUSD_Data `
  --seed-db "\\OLD-PC\share\XAUUSD_CFD_1m_20260815-20261121\xauusd_cfd_klines.db" `
  --once
```

## 9. 常见问题

### Qt 登录后引擎没有启动

检查：

1. `.env` 是否在 `build/apps/pulsetrader_ui/.env`；
2. API key 是否是模拟/测试 key，是否有 Gate TradFi 权限；
3. 网络是否能访问 `api.gateio.ws`；
4. 是否有代理/防火墙拦截；
5. Qt 窗口是否停在登录对话框。

### 历史交易对话框空白或打不开

- Qt 未安装 **Sql** 模块；
- 缺少 `sqldrivers/qsqlite.dll`；
- `sim_orders.db` 路径不一致；
- 新账户没有历史记录（正常）。

### v10 一直 `mode=shadow`

原因通常是 `xau_signal.py` 读取 `external_state.json` 时看到 `engine_running=false` 或状态过期。

处理：

1. 确认 Qt 已启动且引擎运行；
2. 检查 `external_state.json` 的 `updated_at`；
3. 等待下一轮，或重启 v10 runner；
4. 确认 Qt 和 Python 指向同一个 `sim_data_dir`。

### 队列一直 `processing`

- Qt 没有运行或未处理信号；
- 信号已过期，Qt 拒绝；
- 队列消费者异常退出；
- 启动了多个消费者。

处理：

1. 确认只有一个 `xau_signal_queue.py --loop`；
2. 确认 Qt 引擎运行；
3. 重启队列消费者；启动时会自动把卡住的 `processing` 恢复为 `pending`。

### 队列 `accepted` 但 Qt 没有持仓

- 信号是 `none`；
- Qt 判定价格偏离/过期/同策略已有仓位而拒绝；
- 查看 ack 的 `code`、`message`；
- 检查 `strategy_id` 是否一致。

### 构建时 `pulsetrader_ui.exe` 被占用

关闭 Qt；如仍被锁，将旧 exe 改名后重建，或重启相关进程。

### 缺少 Qt DLL / 无法启动

运行 `windeployqt --debug`，并把 `C:\Qt\6.5.3\msvc2019_64\bin` 加入 PATH 仅作为开发机便利；打包时应使用 `windeployqt` 复制依赖。

### Gate 429 / 数据采集过快

- 降低 collector 频率；
- 不要同时启动多个 `gold_snapshot.py`/`xau_store_data.py`；
- 保留 `sleep`/重试；
- 行情接口只返回最近约 500 根，历史数据靠 seed + 持续采集。

## 11. 一句话原则

**Qt 是执行层，`ce` 是策略代码层，`xau_data` 是运行数据层；三者通过 `sim_data_dir`、`data_dir`、`strategy_id`、SQLite 队列和 ack 连接。迁移时优先保证路径一致、队列单实例、Qt 先启动、v10 后启动，其他研究目录不要混入运行目录。**
