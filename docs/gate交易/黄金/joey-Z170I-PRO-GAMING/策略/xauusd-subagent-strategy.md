## 1. 总览

在 pulseTrader 引擎上跑一个常驻后台子代理，对 XAUUSD（Gate.io TradFi 黄金 CFD）做**保守型技术信号剥头皮**：

- 单笔 **0.01 手**（= 1 盎司 ≈ 4,396 USD 名义 ≈ 8.7 USD 保证金 @500x）
- 同时**最多 1 个 CFD 持仓**
- 周期约 25~30 秒一轮：拉行情 → 评估信号 → 执行开平仓 → 风控检查
- 每笔平仓写复盘 md 到 `0_note/`

## 3. 入场信号（≥2 条件共振才开仓）

基于最近 ≥40 根 1m K 线（`get_market` klines=100）：

1. **EMA 交叉**：EMA9 / EMA21 方向一致（金叉做多 / 死叉做空）
2. **RSI(14)**：超卖 <30 做多 / 超买 >70 做空（或顺趋势确认 45 以下/以上）
3. **支撑/阻力**：近期 swing 高低点；价格**贴近**支撑做多、贴近阻力做空

**不交易的情形**：共振 <2 条件、逆势、横盘（EMA 反复粘合假交叉）、无明确方向。

## 4. 出场规则

| 规则 | 触发 | 动作 |
|---|---|---|
| 硬止损 | 持仓 unrealized_pnl ≤ **-5 USD** | 立即平仓 |
| 止盈 | unrealized_pnl ≥ **+8 USD** | 在 +8~+10 区间兑现 |
| 趋势反转 | 反转信号出现 | 提前平仓 |
| 日亏停手 | 当日已实现亏损累计 ≤ **-10 USD** | 当天不再开新仓（已有仓仍按上表管理） |

## 5. 风控与操作协议

- 每轮确认：`trading_halted=false`、无 CFD 持仓、限速 token 充足、余额够保证金
- 开仓：`open_order`（XAUUSD, side, 0.01, market_type=cfd, type=market）—— **必须带 `sl_price`/`tp_price`**（M21 交易所原生附件 price_sl/price_tp,引擎崩溃也生效;2026-08-17 实盘验证：TP 4413.11 由交易所自动平仓 +6.64 USD）。计价：0.01 手 = 1 盎司,1 USD/oz 波动 = 1 USD 盈亏 → 多单 `SL=round(ask-5.0,2)`、`TP=round(ask+8.0,2)`;空单 `SL=round(bid+5.0,2)`、`TP=round(bid-8.0,2)`（2026-08-17 起引擎开仓后 get_positions 立即显示 sl/tp）
- 平仓：`close_position`（position_id 来自 get_positions，默认全平）
- API 报错 → 跳过本轮，**绝不在错误状态下重试下单**
- 异常状态（余额突变、持仓不符）→ 停止交易并记录
- 保守优先：**不确定就什么都不做**
