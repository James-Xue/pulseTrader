# Gate 期货持仓 TP/SL 触发单管理技术备忘

> **生成时间**: 2026-08-16(实战验证:SKHY_USDT 空头 TP 150→151 调整成功)
> **适用范围**: Gate.io 期货合约(`/futures/usdt/...`),USDT 结算;现货/CFD 不适用
> **核心结论**: 持仓的 TP/SL 是**独立的价格触发单**,查持仓的 `close_order` 字段会漏(返回 null ≠ 无保护);调整触发单 PUT 接口不可用,**正确姿势 = 删旧 + 建新**

---

## 1. 三个关键接口

| 端点 | 方法 | 用途 |
|---|---|---|
| `/futures/usdt/positions/{contract}` | GET | 持仓(含 `close_order`/`pending_orders` 字段,**查不到触发单**) |
| `/futures/usdt/price_orders?contract=X&status=open` | GET | **⚠️ 真正的 TP/SL 查询入口** |
| `/futures/usdt/price_orders/{id}` | DELETE | 删除触发单 |
| `/futures/usdt/price_orders` | POST | 创建触发单 |
| `/futures/usdt/price_orders/{id}` | PUT | ⚠️ 修改——**实测报 `AUTO_INVALID_PARAM_ORDER_ID`,不可用** |

## 2. 触发单字段语义

```json
{
  "id": "2088850508826546176",
  "status": "open",
  "order_type": "close-short-position",   // 平空单;多单为 close-long-position
  "direction": "long",                    // 平空=买回(direction long)
  "trigger": {
    "price": "151",
    "rule": 2,                            // 1=价格≥触发(止损方向) 2=价格≤触发(止盈方向)
    "price_type": 0,                      // 0=最新成交价 1=标记价 2=指数价
    "expiration": 0                       // 0=长期有效
  },
  "initial": {
    "contract": "SKHY_USDT",
    "size": 0,
    "price": "0",
    "tif": "ioc",                         // 触发后 IOC 市价单
    "is_reduce_only": true,
    "auto_size": "close"                  // 触发时按持仓数量自动平
  }
}
```

**判定口诀**: 空头持仓 `rule=1`(价格上穿)= SL,`rule=2`(价格下穿)= TP;多单反之。

## 3. 可复用 bash 签名函数(已实测)

```bash
source /path/to/.env   # 含 GATE_MAINNET_API_KEY / GATE_MAINNET_API_SECRET

# 签名格式: METHOD\nPATH\nQUERY\nsha512hex(BODY)\nTIMESTAMP  ← 时间戳在末尾!
# body 哈希: 空 body 用空字符串的 sha512 十六进制
sign_req() { # $1=METHOD $2=PATH $3=QUERY $4=BODY
  local ts hashed sign
  ts=$(date +%s)
  hashed=$(printf '%s' "$4" | openssl dgst -sha512 | awk '{print $2}')
  sign=$(printf '%s\n%s\n%s\n%s\n%s' "$1" "$2" "$3" "$hashed" "$ts" \
    | openssl dgst -sha512 -hmac "$GATE_MAINNET_API_SECRET" | awk '{print $2}')
  local url="https://api.gateio.ws${2}"; [ -n "$3" ] && url="${url}?${3}"
  curl -s -X "$1" -H "KEY: $GATE_MAINNET_API_KEY" -H "Timestamp: $ts" \
    -H "SIGN: $sign" -H "Content-Type: application/json" \
    ${4:+-d "$4"} "$url"
}
```

### 3.1 查询持仓上的 TP/SL

```bash
sign_req GET "/api/v4/futures/usdt/price_orders" "contract=SKHY_USDT&status=open" "" \
  | python3 -m json.tool
```

### 3.2 调整 TP/SL = 删旧建新(核心模式)

```bash
TP_ID=2088850508826546176   # 要替换的旧触发单 ID

# ① 删旧
sign_req DELETE "/api/v4/futures/usdt/price_orders/$TP_ID" "" "" 

# ② 建新(改 trigger.price / rule 即可;其余字段照抄原单)
BODY='{"initial":{"contract":"SKHY_USDT","size":0,"price":"0","tif":"ioc","text":"app","iceberg":0,"is_close":false,"is_reduce_only":true,"auto_size":"close","amount":"0","iceberg_amount":"0"},"trigger":{"strategy_type":0,"price_type":0,"price":"151","rule":2,"expiration":0},"order_type":"close-short-position"}'
sign_req POST "/api/v4/futures/usdt/price_orders" "" "$BODY"

# ③ 验证
sign_req GET "/api/v4/futures/usdt/price_orders" "contract=SKHY_USDT&status=open" "" \
  | python3 -c "import json,sys; [print(o['trigger']['price'], 'rule='+str(o['trigger']['rule']), o['status']) for o in json.load(sys.stdin)]"
```

## 4. 踩坑清单(全部实战验证)

1. **`close_order` 字段查不到触发单**:持仓 API 里 `close_order: null` / `pending_orders: 0` ≠ 无保护 —— 触发单存在独立的 `price_orders` 接口,必须单独查。初版 SKHY 分析报告因此误判"无保护单"。
2. **PUT 修改不可用**:`PUT /price_orders/{id}` 报 `AUTO_INVALID_PARAM_ORDER_ID`(带完整合法 body 也一样)→ 改用删旧建新。
3. **签名时间戳在末尾**:Gate v4 签名字符串 = `METHOD\nPATH\nQUERY\nsha512hex(BODY)\nTIMESTAMP`,不是 `timestamp+method+path` 拼接。BODY 为空时用空串的 sha512。
4. **shell 变量名陷阱**:请求路径别用 `PATH` 作变量名(会覆盖环境变量 PATH,导致 date/openssl/curl 全部 not found)。用 `REQ_PATH`。
5. **触发基准**:默认 `price_type=0` 按**最新成交价**触发 + IOC 市价平 —— 快速插针行情下触发后仍有滑点,极端情形可能落到强平价附近执行。
6. **方向匹配**:`close-short-position` 触发单只在存在空头持仓时有效;无持仓时会怎样需要实测(建议挂单前先确认持仓存在)。
7. **主网真钱**:删旧建新之间是毫秒级窗口,但任何一步失败都会留下"只有 SL 没有 TP"的中间态 —— 先建新再删旧可进一步缩短风险窗口(建新成功前不删旧)。

## 5. 附:SL/TP 与强平的距离关系(仓位保护设计参考)

空头持仓(SKHY 实例):entry 161.84,现价 168.46,强平 173.02
- SL 170.5(rule=1):最大亏损锁定 (170.5-161.84)×4000×0.01 ≈ **-346.5 USDT**(早于强平 1.2% 触发)
- TP 151(rule=2):目标盈利 (161.84-151)×4000×0.01 ≈ **+433.5 USDT**
- 经验:SL 应放在强平线**下方**(空头)/**上方**(多头)留出空间;距离太近(如本次 +1.21%)在趋势行情中极易被日内波动扫掉
